---
name: Record filter UI contract
description: 기록 탭 필터와 보기 전환 UI의 확정된 상호작용 형태
---

기록 탭의 종류 선택은 `단상`, `편집`, `편지`가 각각 항상 보이는 독립 버튼이어야 한다. 하나의 드롭다운이나 선택 캡슐로 합치지 않는다. 보기 방식은 별도의 아이콘 버튼으로 유지한다.

**Why:** 다른 작업 브랜치 병합 과정에서 드롭다운 필터 UI가 반복해서 재유입되었고, 사용자가 독립 버튼 형태를 명시적으로 유지해 달라고 확인했다.

**How to apply:** 기록 탭이나 폴더 상세 관련 변경을 병합할 때 기록 탭 화면의 필터 렌더링까지 함께 덮어쓰지 않았는지 확인한다. 회귀 테스트는 드롭다운 부재와 세 종류 독립 버튼 존재를 검증해야 한다.
