name: Record filter UI contract
description: 기록 탭 필터와 보기 전환 UI의 확정된 상호작용 형태
---

기록 탭의 종류 선택은 `단상`, `편집`, `편지`가 각각 항상 보이는 독립 버튼이어야 한다. 하나의 드롭다운이나 선택 캡슐로 합치지 않는다. 보기 방식은 별도의 아이콘 버튼으로 유지한다.

기록 화면은 `편지`를 기본 보기로 열고, 질문 카드는 별도 질문 전용 화면처럼 목록을 대체하지 않고 편지 카드 사이에 섞여야 한다. 질문 큐 조회는 보조 요청이므로 실패해도 이미 불러온 편지 목록을 가리거나 반복 오류 알림으로 방해하지 않는다.

**Why:** 다른 작업 브랜치 병합 과정에서 드롭다운 필터 UI와 질문 전용 기본 화면이 반복해서 재유입되었고, 사용자가 독립 버튼 및 편지 중심 혼합 목록 형태를 명시적으로 유지해 달라고 확인했다.

**How to apply:** 기록 탭이나 폴더 상세 관련 변경을 병합할 때 기본 종류, 질문 혼합 조건, 필터 렌더링을 함께 확인한다. 회귀 테스트는 편지 기본 선택, 편지 사이 질문 혼합, 드롭다운 부재, 세 종류 독립 버튼 존재를 검증해야 한다.
