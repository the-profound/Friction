# iOS 긴 글 붙여넣기 실기기 확인

## 준비

1. iOS 실기기에서 개발 빌드를 열고 작성 화면으로 이동한다.
2. 제목과 여러 문단을 포함한 3,000자 이상의 텍스트를 클립보드에 준비한다.
3. 글자 수와 자동 저장 결과를 비교할 수 있도록 원문 글자 수를 기록한다.

## 확인 절차

1. 본문 중간에 커서를 놓고 긴 텍스트를 한 번에 붙여넣는다.
   - 붙여넣은 본문과 캐럿이 서식 툴바 및 키보드 위에 보여야 한다.
   - 화면 대부분을 차지하는 빈 영역이나 본문이 사라진 것처럼 보이는 구간이 없어야 한다.
2. 키보드를 유지한 채 문서의 처음과 끝까지 스크롤한다.
   - 모든 문단이 자연스럽게 이어지고 끝에서 과도한 빈 공간이 없어야 한다.
3. 서식 툴바의 키보드 닫기 버튼으로 키보드를 닫은 뒤 다시 본문을 탭한다.
   - 닫기와 재열기 직후에도 기존 스크롤 범위와 현재 입력 위치가 유효해야 한다.
4. 붙여넣은 본문 일부에 굵게, 기울임, 밑줄, 인용 서식을 적용한다.
   - 툴바가 키보드 바로 위에 유지되고 선택 영역을 가리지 않아야 한다.
5. 잠시 기다린 뒤 화면을 나갔다가 다시 열어 글자 수와 저장된 본문을 확인한다.
   - 붙여넣은 전체 내용과 서식이 유지되어야 한다.
6. 단상 작성 화면에서 검토 단계로 전환한다.
   - 전환 후에도 전체 본문이 유지되고 페이지 검토 화면이 정상적으로 열린다.

## 플랫폼 회귀 확인

- Android: 긴 붙여넣기, 키보드 닫기/재열기, 처음부터 끝까지 스크롤을 동일하게 확인한다.
- Web: 일반 작성과 자동 저장, 글자 수, 검토 전환이 기존대로 동작하는지 확인한다.
