3.3 기록함 · 문장 선택

선택 모드에는 NavBar 대신 화면 하단 absolute 삭제 바가 생깁니다. 목록 reserve와 바의 내부 padding은 서로 다른 역할입니다.

  • 선택 헤더paddingTop: 50 · paddingBottom: 20
  • 삭제 바 위치bottom: 0 · NavBar 대신 하단 chrome
  • 삭제 바 내부 하단inset.bottom + 20 + 68 + 12
  • 목록 하단 reserveinset.bottom + 20 + 68 + 80

삭제 바의 내부 padding으로 목록 하단 padding을 대체하면 마지막 항목이 바 아래로 들어갑니다. 선택 모드의 80은 별도 시각 reserve입니다.

도면을 읽는 핵심: 청록/노랑은 화면의 물리적 가장자리를 피하기 위한 값이고, 보라는 NavBar가 있을 때 콘텐츠를 스크롤 가능하게 만드는 값입니다. 반면 주황/파랑은 리더 카드 내부의 논리적 본문 지오메트리입니다. 이름에 safeArea가 들어가도 주황 영역은 기기 노치나 홈 인디케이터와 무관합니다.
