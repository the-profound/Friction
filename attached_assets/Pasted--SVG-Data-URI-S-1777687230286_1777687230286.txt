# 개요

종이 질감 구현 시 매 페이지마다 SVG 필터를 Data URI로 삽입하면 브라우저가 반복적으로 파싱/계산해야 하므로 성능 저하가 발생합니다. 이를 해결하기 위해 **SVG 필터를 앱 최상단에서 한 번만 정의하고, 모든 페이지에서 참조하는 방식**으로 최적화합니다.

---

## 최적화 방안: SVG 전역 참조 방식

### 핵심 아이디어

- SVG 필터를 `<defs>` 태그로 한 번만 선언하여 DOM에 등록
- 각 페이지는 `filter: url(#paperRoughness)` 형태로 참조만 수행
- 브라우저가 필터를 캐싱하여 재사용하므로 연산 부담 최소화

### 구현 방법

**1단계: 앱 최상단에 SVG 필터 정의**

`App.js` 또는 `Layout.js`의 최상단에 다음 코드를 추가합니다.

```jsx
// App.js 또는 Root Layout Component
function App() {
  return (
    <>
      {/* SVG 필터 정의 (화면에 보이지 않음) */}
      <svg 
        style=
          position: 'absolute',
          width: 0,
          height: 0,
          overflow: 'hidden'
        
        aria-hidden="true"
      >
        <defs>
          <filter id="paperRoughness">
            <feTurbulence
              type="fractalNoise"
              baseFrequency="0.8"
              numOctaves="3"
              result="noise"
            />
            <feDiffuseLighting
              in="noise"
              lightingColor="white"
              surfaceScale="1.5"
              result="diffuse"
            >
              <feDistantLight azimuth="45" elevation="60" />
            </feDiffuseLighting>
          </filter>
        </defs>
      </svg>

      {/* 나머지 앱 콘텐츠 */}
      <AppContent />
    </>
  );
}
```

**2단계: CSS에서 필터 참조**

각 페이지 컴포넌트의 CSS에서 다음과 같이 적용합니다.

```css
.paper-texture {
  position: relative;
  background-color: var(--page-bg-color); /* 라이트/다크 모드 대응 */
}

.paper-texture::before {
  content: "";
  position: absolute;
  inset: 0;
  pointer-events: none;
  
  /* SVG 필터 참조 */
  filter: url(#paperRoughness);
  
  /* 질감 강도 조절 */
  opacity: 0.4;
  
  /* 블렌딩 모드 */
  mix-blend-mode: multiply;
}
```

**3단계: GPU 가속 활성화 (추가 최적화)**

페이지 전환 시 부드러운 애니메이션을 위해 GPU 레이어로 승격합니다.

```css
.paper-texture::before {
  /* ... 기존 속성 ... */
  
  /* GPU 가속 */
  will-change: transform;
  transform: translateZ(0);
}
```

## 기존 방식과의 비교

### 기존: Data URI 방식 (느림)

```css
.paper-texture::before {
  background-image: url("data:image/svg+xml,%3Csvg...");
  /* 매번 SVG 파싱 발생 */
}
```

- **문제점**: 매 페이지마다 Data URI를 새로 파싱
- **성능**: 페이지가 많을수록 누적 부담 증가

### 개선: 전역 참조 방식 (빠름)

```css
.paper-texture::before {
  filter: url(#paperRoughness);
  /* ID 참조만 하므로 즉시 적용 */
}
```

- **장점**: 한 번만 파싱, 이후 재사용
- **성능**: 페이지 수와 무관하게 일정한 성능

---

## 장점

✅ **절대 안 깨지는 화질**: 벡터 방식이므로 모든 해상도에서 선명  

✅ **간단한 구현**: SVG 복사-붙여넣기만 하면 완료 (5분 소요)  

✅ **동적 조정 가능**: CSS 변수로 색상/강도 실시간 변경 가능  

✅ **용량 극소**: 몇 백 바이트 수준  

✅ **다크모드 대응**: CSS 변수만 전환하면 자동 적용

## 브라우저 호환성

- **지원**: Chrome, Firefox, Safari (iOS 13+), Edge
- **미지원**: iOS 12 이하 일부 구형 브라우저
- **폴백**: 미지원 브라우저는 질감 없이 단색 배경만 표시 (기능 정상 작동)

```css
/* 폴백 처리 예시 */
@supports not (filter: url(#paperRoughness)) {
  .paper-texture::before {
    /* 단순 그레이디언트로 대체 */
    background: linear-gradient(135deg, #fdfbf7 0%, #f5f3ef 100%);
  }
}
```

## 향후 확장 가능성

### Backlog: 여러 질감 프리셋

사용자가 선택할 수 있도록 다양한 질감을 제공할 경우:

```jsx
<defs>
  <filter id="paperRoughness-smooth">
    <feTurbulence baseFrequency="0.5" numOctaves="2" />
    {/* 부드러운 질감 */}
  </filter>
  
  <filter id="paperRoughness-rough">
    <feTurbulence baseFrequency="1.2" numOctaves="4" />
    {/* 거친 질감 */}
  </filter>
</defs>
```

```css
.paper-texture-smooth::before {
  filter: url(#paperRoughness-smooth);
}

.paper-texture-rough::before {
  filter: url(#paperRoughness-rough);
}
```

---

## 참고 자료

- **feTurbulence**: 프랙탈 노이즈 생성 (자연스러운 불규칙성)
- **feDiffuseLighting**: 가상 조명으로 입체감 부여
- **mix-blend-mode: multiply**: 배경색과 질감을 곱하기 방식으로 합성
