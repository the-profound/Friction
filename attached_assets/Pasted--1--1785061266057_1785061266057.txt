# 공간 기능 수정 보완 — 설계 결정 및 변경 사항 정리

## 1. 공간 상태 전환 구조 변경

### 기존 문제
- 시작 날짜가 도달해도 모집 중에서 진행 중으로 자동 전환되지 않음
- 모집 마감 시점이 명확하지 않음
- 참여자 확정 상태, 여는 편지 유무 등 시작 전제 조건 미정의

### 변경 내용

모집 중 → 진행 중 → 종료됨

#### 상태 흐름

- **모집 중**: 공간 생성 직후 상태. 초대 수락·코드 신청·운영자 승인 모두 가능
- **시작 예정일 경과 (별도 상태 아님)**: 시작 예정일이 지나도 상태는 모집 중으로 유지. 별도 상태를 만들지 않고, 모집 중 상태에서 시작 예정일 경과 여부를 파생 조건으로 계산해 UI를 분기. 운영자 화면에는 "공간 시작하기" CTA를 더 강조해 노출. 참여자에게는 "운영자가 곧 시작할 예정" 안내
- **진행 중**: 운영자가 "공간 시작하기" 버튼을 누르면 진행 중으로 전환. 동시에 모집 자동 마감
- **종료됨**: 읽기만 가능, 답장·예약 발송 제한

#### 시작 예정일 개념
- 기존 "시작 날짜"를 "시작 예정일"로 변경
- 시작 예정일은 참여자에게 안내하는 예정일일 뿐, 실제 시작 시점이 아님
- 실제 시작 시점 = 운영자가 "공간 시작하기" 버튼을 누른 시점
- 시작 예정일을 이미 지난 날로 설정한 경우: 생성 직후 모집 중으로 열리고, 바로 시작 예정일 경과 상태로 간주해 시작 CTA를 강조 노출

#### 모집 마감 처리
- 모집 마감 시점 = 운영자가 공간을 시작하는 시점 (자동 마감)
- 마감 시 승인 대기 중인 코드 신청자는 **자동 거절** 처리, 거절 안내 발송
- 마감 이후 새 신청 수락 불가, 마감 안내 노출

#### 운영자 미접속 알림
- 시작 예정일 경과 후 운영자가 시작하지 않은 경우 단계별 알림:
  - 경과 다음날 / 3일 / 7일: 운영자에게 시작 안내 알림
  - 14일 경과: 참여자에게 시작 지연 안내 + 운영자에게 공간 보관 또는 시작 예정일 연장 옵션 제공

## 2. 공간 생성 시점과 시작 시점 설정 분리

### 기존 문제
- 공간 생성 시 모든 설정(회차 수, 간격, 중심글 개수, 회차별 제목·설명)을 한 번에 입력해야 함
- 생성 시점에 전체 회차 틀을 미리 만드는 구조

### 변경 내용

#### 공간 생성 시 입력 항목 (예정값)
- **기본 설정**: 제목, 설명, 익명 여부
- **운영 설정**: 시작 예정일, 예정 회차 수, 모집 인원
- **고급 설정**: 예정 중심글 간격 (기본값 1일), 예정 중심글 개수 (기본값 1개)
- 회차별 제목·설명 입력은 **생성 시점에서 제거** → 시작 시점으로 이동

#### 공간 시작 시점에 확정하는 항목
- 운영 설정 확정: 회차 수, 중심글 간격, 중심글 개수 (생성 시 예정값을 기본값으로 불러와 수정 가능)
- 회차 구성: 회차별 제목, 회차별 짧은 설명
- 중심글 작성 순서 배정: 확정 참여자 기준
- 1회차 여는 편지 작성 여부

#### 회차 틀 생성 시점 변경
- **기존**: 공간 생성 시 입력한 회차 수와 중심글 규칙을 바탕으로 전체 회차 틀을 미리 생성
- **변경**: 회차 틀은 공간 시작 시점에 확정한 회차 수와 중심글 규칙을 바탕으로 생성. 회차에는 회차 번호, 제목, 짧은 설명, 예정 상태, 시작 조건, 기본 규칙을 저장

#### 생성 확인 단계
- 기본 설정, 운영 설정, 고급 설정을 바탕으로 "언제 시작할 예정이고 어떻게 진행될 예정인지" 요약 표시
- 회차별 제목·설명은 생성 확인에서 제거 (시작 시점으로 이동)
- 공간 만들기 후 모집 중 상태로 열리고, 초대·코드 공유 안내 표시

## 3. 공간 시작 화면 (신규)

### 화면 개요
- 운영자가 확정된 참여자 구성에 맞춰 회차를 구성하고, 공간을 진행 중으로 전환하는 화면
- 진입 경로: 공간 상세 화면의 "공간 시작하기" CTA (모집 중 상태에서 운영자에게 노출, 시작 예정일 경과 시 강조)

### 화면 구조
- 상단: 공간 이름, 시작 예정일
- 본문: 운영 설정 확정 / 회차 구성 / 중심글 작성 순서 배정 / 1회차 여는 편지 준비 상태
- 하단: 공간 시작하기 CTA

### 필수 정보
- 참가자 정보: 확정 인원 / 모집 인원
- 운영 설정: 회차 수, 중심글 간격, 중심글 개수 (생성 시 예정값을 기본값으로 불러와 수정 가능)
- 회차 구성: 회차별 제목, 회차별 짧은 설명
- 중심글 작성 순서: 확정 참여자 기준 배정
- 1회차 여는 편지 작성 여부

### 보조 정보
- 시작과 동시에 모집이 마감된다는 안내
- 승인 대기 중인 코드 신청자는 자동 거절 처리된다는 안내
- 시작 후에는 회차 수·간격 같은 핵심 규칙을 수정할 수 없다는 안내

### 예외 처리
- **1회차 여는 편지 미작성**: 공간 시작하기 비활성화, "여는 편지를 먼저 작성해주세요" 안내
- **확정 참여자 0명**: 공간 시작하기 비활성화, "최소 1명의 참여자가 있어야 시작할 수 있습니다" 안내
- **확정 참여자 < 모집 인원**: "현재 N명이 참여 중입니다. 그대로 시작하시겠습니까?" 확인창. 모집을 더 진행하거나 시작 예정일을 늦출 수 있음
- **시작 예정일 경과 후 미시작**: 운영자에게 단계적 시작 안내 알림, 참여자에게 지연 안내. 장기간 미시작 시 보관 또는 예정일 연장 제안

### 시작 버튼 활성화 조건
1. 1회차 여는 편지가 작성되어 있을 것
2. 확정 참여자가 최소 1명 이상일 것
3. (참여자가 모집 인원 미달인 경우 확인창 승인)

### 시작 처리 로직
- 공간 시작하기 → 진행 중 전환, 모집 자동 마감, 승인 대기 중인 코드 신청자 자동 거절, 공간 상세 화면으로 이동
- 회차 틀 생성: 시작 시 확정한 회차 수와 중심글 규칙을 바탕으로 전체 회차 틀 생성

## 4. 공간 상세 화면 변경

### 추가된 내용
- 보조 행동에 "(운영자) 공간 시작하기 (모집 중 상태) → 공간 시작 화면" 추가
- 운영자 상태에 "모집 중 상태에서는 공간 시작하기 CTA를 함께 제공하고, 시작 예정일이 지나면 더 강조" 추가

### 상태별 변경 사항
- **시작 전 공간 (모집 중)**: 회차 틀이 아직 확정되지 않았으므로 시작 예정일·예정 회차 수·예정 진행 방식 같은 예정 운영 계획만 표시. 편지 카드와 답장 행동 제한. 운영자는 모집·승인 관련 행동 계속 가능
- **시작 예정일 경과**: 시작 예정일이 지나도 상태는 모집 중으로 유지. 운영자에게 공간 시작하기 CTA를 더 강조해 노출, 참여자에게는 운영자가 곧 시작할 예정이라는 안내. 모집은 계속 열려 있음
- **모집 마감**: 운영자가 공간을 시작하는 시점에 모집을 자동 마감. 승인 대기 중인 코드 신청자는 자동 거절 처리하고 거절 안내를 보냄. 이후 새 신청 수락 불가, 마감 안내

---

## 5. 공간 목록 화면 변경

### 진행 상태 표기
- 기존: 시작 전 / 진행 중
- 변경: 모집 중 / 진행 중 (시작 예정일 경과는 모집 중 상태의 보조 표시로 처리)

### 정렬 기준
- 일반 카드 1순위: 진행 중 > 모집 중
- 진행 중 공간: 마지막 접속 순
- 모집 중 공간: 시작 예정일 임박 순. 시작 예정일이 이미 지난 공간을 그 앞에 둠

### 상태 전환 안내
- 공간 상태는 모집 중 → 진행 중 → 종료됨 세 단계. 시작 예정일 도달만으로는 상태가 바뀌지 않고, 운영자가 공간 시작하기를 눌러야 진행 중으로 전환

---

## 6. 공간 참여 화면 변경

### 운영 일정 표기
- 기존: 시작일, 예상 종료일, 진행 회차, 진행 주기
- 변경: 시작 예정일, 예상 종료일, 예정 회차 수, 예정 진행 주기
- "실제 회차 구성은 공간 시작 시점에 확정된다"는 점을 함께 안내

### 의존 내용 추가
- 모집은 운영자가 공간을 시작하는 시점에 자동 마감. 시작 예정일이 지난 뒤에도 공간이 시작되기 전까지는 초대 수락과 코드 신청이 가능. 공간이 시작되면 승인 대기 중인 코드 신청자는 자동 거절 처리

### 예외 상태별
- 모집 마감: 수락·신청 버튼 비활성화, 마감 안내 노출. 공간 시작 시 승인 대기 중인 신청자는 자동 거절되며 거절 안내를 받음

---

## 7. 회차 관리 화면 변경

### 전제 변경
- 기존: "회차는 공간 생성 시점에 전체 틀을 미리 만든다"
- 변경: "회차 틀은 공간 시작 시점에 확정해 만든다"

### 의존 내용
- 공간 시작 시점에 확정한 회차 수와 중심글 규칙을 바탕으로 전체 회차의 틀이 생성됨

### 제외 범위
- "회차 제목·설명을 처음 구성하는 일" → 공간 시작 화면에서 다룸

---

## 8. 글 예약 발송 화면 변경

### 의존 내용 추가
- 회차 구성과 중심글 작성 순서는 공간 시작 시점에 확정됨

---

## 9. 공통 설정 항목 (synced block) 변경

### 공간 생성 화면 내 공통 설정 항목
- 기본 설정: 제목, 설명, 익명 여부
- 운영 설정: **시작 예정일**, **예정 회차 수**, 모집 인원
- 회차 구성 (**공간 시작 시 확정**): 회차별 제목, 회차별 짧은 설명, 중심글 작성 순서
- 고급 설정: **예정** 중심글 간격 (기본값 1일), **예정** 중심글 개수 (기본값 1개)

### 생성 화면 단계 축소
- 기존: 기본 설정 → 운영 설정 → 회차 구성 → 고급 설정 → 생성 확인
- 변경: 기본 설정 → 운영 설정 → 고급 설정 → 생성 확인
