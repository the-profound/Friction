[작업] TipTap 기반 마크다운 에디터(ON-01a/검토 단계)에서 "사진 자동 분할"을 구현해줘.
검토 단계 진입 시, 본문에 삽입된 사진을 단독 페이지로 분리한다. "사진 1장 = 1페이지".

[페이지 모델 — 먼저 합의]
- 페이지 경계 = 분할선(HorizontalRule, `---`). 본문은 `---` 기준으로 페이지가 나뉜다.
- 마감/읽기 뷰는 `---` 사이 구간을 1페이지로 렌더한다. (자동분할은 이 모델 위에서만 의미가 있음)
- 선행 의존성: 에디터의 HR 노드 삽입/렌더가 안정적으로 동작해야 함(BTIS051).
  순서: HR 노드 안정화 → 자동분할 → 뷰어 페이지 경계 렌더.

[이미지 노드 전제]
- 이미지는 TipTap 스키마에서 "블록 레벨 노드"여야 한다. (인라인 이미지 노드 금지)
- 작성 단계에서 커서 위치(문장 중간)에 삽입돼도, 삽입 시점 또는 검토 진입 시점에
  블록 이미지 노드로 승격한다. (표시 CSS는 display:block, max-width:60%, max-height:280px)
- 원본 파일(원래 해상도)은 절대 다운스케일/재인코딩하지 말 것. 표시 크기만 제어.

[자동분할 알고리즘 — 검토 단계 진입 시 1회 실행]
Step 0) 인라인 이미지 문단 분리(가장 중요):
   이미지가 텍스트와 같은 문단 안에 있으면(`텍스트…[이미지]…텍스트`),
   이미지 경계에서 문단을 split 하여 `[앞 텍스트] / 이미지 / [뒤 텍스트]` 구조로 만든다.
   앞/뒤 텍스트가 비면 빈 문단은 만들지 않는다.
Step 1) 본문 노드 트리를 순회해 모든 (블록) 이미지 노드 위치를 수집한다.
Step 2) 각 이미지의 바로 위·바로 아래에 HR이 없으면 삽입한다.
Step 3) 중복 방지: 이미 HR이 인접하면 추가 삽입하지 않는다.
   이미지와 HR 사이에 "빈 문단만" 있는 경우도 이미 분할된 것으로 간주(빈 문단 무시).
Step 4) 멱등성 마킹: 처리한 이미지에 노드 attribute(data-autosplit="1")를 부여한다.
   재진입(DRAFT↔검토 왕복, 검토에서 사진 추가 후 재실행) 시 마킹된 이미지는 다시 건드리지 않는다.
   사용자가 HR을 수동으로 옮기거나 지워도 마킹 기준으로 재생성하지 않는다.
Step 5) 경계 처리: 이미지가 본문 맨 앞/맨 뒤(또는 빈 문단만 있는 경우)면 바깥쪽 HR은 생략.
   HR 뒤에는 커서가 설 수 있도록 trailing paragraph를 보장한다.
Step 6) 사진 연속 금지: 사진-사진이 텍스트 페이지 없이 인접하면 사이에 "빈 본문 페이지"
   (빈 문단 1개)를 자동 삽입한다. 비차단 Toast로 "사진 사이에 빈 페이지를 추가했어요" 안내.
Step 7) 위 분리·삽입은 단일 트랜잭션으로 처리(한 번의 Undo로 원복).
   자동 저장(debounce)과 충돌하지 않도록 트랜잭션 완료 후 저장 트리거.

[하지 말 것]
- 이미지를 크롭하거나 강제 비율로 자르지 말 것(표시 박스만 적용, 원본 비율 유지).
- 원본 파일을 압축/리사이즈해서 저장하지 말 것.
- 분할선을 중복으로 두 줄 만들지 말 것.

[수용 기준 — 아래 6개 픽스처가 전부 통과해야 함]
1. 문장 중간 사진:   P("앞 [IMG] 뒤")        → P("앞") / HR / IMG / HR / P("뒤")
2. 맨 앞 사진:       IMG / P("본문")         → IMG / HR / P("본문")  (위쪽 HR 생략)
3. 사진 2장 연속:    IMG / IMG               → IMG / HR / P("") / HR / IMG  (빈 본문 페이지 삽입)
4. 이미 분할선 존재: HR / IMG / HR           → 변화 없음(중복 삽입 안 함)
5. 빈 문단 끼임:     P("") / IMG / P("")     → 빈 문단 무시, 이미 분할로 간주(중복 HR 없음)
6. 재진입:           data-autosplit="1" 마킹 이미지 → 재실행해도 변화 없음
